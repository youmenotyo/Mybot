# بوت رماية السهم 🏹

بوت ديسكورد فيه لعبتين:

- **`/رماية_تدريب`** — يحدد هدف بمسافة عشوائية، تتحكم بالقوة والزاوية عبر أزرار، وتحاول توصل أقرب ما يمكن للهدف.
- **`/رماية_تحدي [المسافة]`** — لازم توصل بالسهم لأبعد من المسافة المحددة (ولو بمتر واحد). لو ما حددت مسافة، البوت يختار وحدة عشوائية.

### عوائق عشوائية 🌬️🏔️

كل جولة جديدة (حتى لو نفس الهدف أو نفس المسافة المطلوبة) يتم اختيار:

- **ارتفاعك عن الهدف** (0-40 متر) — كلما زاد الارتفاع طال وقت سقوط السهم فزادت المسافة.
- **سرعة الرياح** (-15 إلى +15 م/ث) — رياح موجبة تدفع السهم لمسافة أبعد، ورياح سالبة (معاكسة) تقصّر المسافة.

يعني ما ينفع اللاعب يحفظ رقم قوة وزاوية معينة ويكررهم كل مرة ويتوقع نفس النتيجة — لازم يقرأ الظروف الظاهرة بالرسالة ويعدّل بناءً عليها.

## 1) إنشاء البوت في Discord Developer Portal

1. روح إلى https://discord.com/developers/applications واضغط **New Application**.
2. من تبويب **Bot**، اضغط **Add Bot**، وانسخ الـ **Token** (بتحتاجه بالخطوة 3).
3. تأكد إن **Message Content Intent** مو ضروري هنا لأن البوت يستخدم أوامر Slash فقط.
4. من تبويب **OAuth2 → URL Generator**:
   - Scopes: `bot`, `applications.commands`
   - Bot Permissions: `Send Messages`, `Embed Links`, `Use Slash Commands`
   - انسخ الرابط الناتج وافتحه لإضافة البوت لسيرفرك.
